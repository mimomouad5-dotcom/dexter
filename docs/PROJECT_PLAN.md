# خطة المشروع الشاملة — Dexter Presentation Studio

> توثيق تفصيلي لمراحل التنفيذ وفق وثيقة المعمارية والمخطط الداخلي المعتمد.

## ملخص المراحل والمكونات المستهدفة

| المرحلة | الاسم | المكونات المستهدفة من المخطط | معيار القبول الرئيسي |
|---|---|---|---|
| **0** | **إثبات الجدوى (PoC)** | poc/01 إلى poc/06 (n8, n9, n10, n11, n14, n27, n28, n29, n34) | اكتمال تجارب النافذة، PPTX الأصلي، الحركات OOXML، فحص Ollama، الفهرسة، وIPC مع تقرير مكتمل |
| **1** | **هيكل التطبيق** | n2 (هيكل الشاشات n3-n7)، n8 (n9, n10, n11)، n13 (n14)، n32 | إقلاع متزامن لـ Electron وPython مع تحقق التوكن، ورفض الطلبات غير المصرح بها |
| **2** | **التخزين والإعدادات** | n40 (SQLite)، n41 (JSON)، n44 (الأسرار)، n31 (النسخ)، n7 (الإعدادات) | حفظ الإعدادات، النسخ والاستعادة، تخزين المفاتيح في مخزن الأسرار الآمن دون ظهورها في أي ملف |
| **3** | **معالج إنشاء العرض** | n3 (Wizard & Outline Review) | جمع الإعدادات والمخطط اليدوي وحفظ ترتيب وعناصر المخطط بدقة |
| **4** | **نموذج بيانات الشرائح** | n23 (Unified Model: Slides/Elements/Notes) | التحقق الصارم بـ Pydantic وJSON Schema وتوليد أنواع TS، وحفظ Round-trip دون فقدان |
| **5** | **تصدير PowerPoint** | n27 (python-pptx + OOXML)، n28 (Verified animations)، n46 (.pptx) | ملف PPTX قابل للتحرير بالكامل، محاذاة RTL عربية سليمة، تطابق تام مع النموذج |
| **6** | **مكتبة القوالب والبيانات** | n29 (Importer/Classifier/Dedupe)، n42 (Library Folder)، n6 (UI)، n16 (Tasks) | فهرسة دفعية، كشف التكرار SHA-256، قراءة فقط، إلغاء آمن دون إفساد قاعدة البيانات |
| **7** | **موفّر الذكاء الاصطناعي المحلي** | n18 (Provider Manager: Local)، n34 (Ollama / Local API)، n7 (Provider UI) | اكتشاف توفر Ollama، رسائل واضحة عند الغياب، منع الاتصال الخارجي في هذا الوضع |
| **8** | **توليد المخطط والمحتوى** | n19 (Outline & Content Generator)، n3 (Outline Review UI)، n23 (Model) | توليد منظم للمخطط أولاً ومراجعته ثم المحتوى لكل شريحة، حفظ مدخلات المستخدم |
| **8ب** | **المزودات الخارجية** | n36 (Consent Gate)، n37 (External Adapters)، n7 (Keys & Tasks Policy) | حظر الإرسال الخارجي إلا بعد موافقة صريحة، حقن آمن للمفاتيح، توثيق الخصوصية |
| **9** | **البحث والأدلة** | n21 (Sources & Claims Log)، n6 (Sources UI) | تسجيل المصادر بروابط ومقتطفات، وسم الادعاءات غير المدعومة، إعلان غياب الأداة |
| **10** | **الصور والرسوم البيانية** | n22 (Images & Native Charts: License Tracking) | رسوم PowerPoint تفاعلية أصلية، توثيق تراخيص الصور ومصادرها |
| **11** | **محرك التصميم** | n24 (Layouts & Themes)، n26 (Quality Inspector)، n5 (Design Preview) | ثبات المحتوى (apply_design لا يحذف أي عنصر)، فحص التباين والفيض، معاينة بدائل متعددة |
| **12** | **المحرر المتقدم** | n4 (Slide Canvas, Thumbnails, Undo/Redo, Notes) | تحرير تفاعلي، شجرة Undo/Redo بنمط Command، حفظ تلقائي وتطابق المعاينة مع التصدير |
| **13** | **الحركات والانتقالات** | n28 (Verified Effects Registry)، n4 (Animation Inspector) | قصر الحركات على التأثيرات المختبرة والمتحقق منها فقط بـ OOXML |
| **14** | **التعلّم من التفضيلات** | n30 (Preference Learning: Ranking, opt-out) | خوارزمية ترتيب محلية قابلة للتفسير، خيارات تعطيل ومسح وتصدير |
| **15** | **إدارة المهام الشاملة** | n16 (Tasks Manager: Progress/Cancel/Resume)، n32 (Safe Logger) | دعم نقاط الاستئناف (Checkpoints)، حجب تام للأسرار في السجلات |
| **16** | **مراجعة الأمان والتكامل** | مراجعة شاملة لجميع المكونات E1 إلى E20 | تدقيق التراخيص، اختبارات الأمان ضد الحقن والملفات الخبيثة، اختبارات E2E كاملة |
| **17** | **حزمة Windows** | n11 (Python مجمعة)، المثبّت (Installer) | تثبيت نظيف على Windows 10/11 x64 بدون متطلبات تطوير مسبقة |
