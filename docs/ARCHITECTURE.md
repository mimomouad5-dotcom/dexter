## فهرس المكونات المعمارية والمسؤوليات

### 1. طبقة واجهة المستخدم [n2] (Electron Renderer - React + TypeScript)
- **n3 معالج إنشاء العرض (Wizard & Outline Review):** إدخال الموضوع والمطالبة وإعدادات الجمهور والنمط والتفاصيل، مع شاشة مراجعة المخطط التفاعلية قبل التوليد النهائي.
- **n4 محرر الشرائح (Undo/Redo, Thumbnails, Canvas):** تحرير النصوص والأشكال والصور والجداول، شريط المصغرات، ملاحظات المتحدث، وسجل التراجع والتقدم بنمط Command.
- **n5 معاينة التصاميم (Design Preview):** توليد 3 إلى 6 بدائل تخطيط وتنسيق على نفس المحتوى دون حذف أي عنصر.
- **n6 المكتبة والمراجع (Library & Sources):** تصفح القوالب والملفات المفهرسة، كشف المكررات، وسجل تدقيق الادعاءات والمصادر.
- **n7 الإعدادات ومفاتيح الـ API (Settings, Providers, Privacy):** إدارة مزودات الذكاء الاصطناعي، سياسات الخصوصية، التعلم المحلي، والنسخ الاحتياطي.

### 2. طبقة المعالجة الرئيسية [n8] (Electron Main Process)
- **n9 Preload المحدود (contextIsolation):** جسر آمن يعرّض `window.api` فقط مع التحقق الصارم من المدخلات بواسطة Zod. حظر كامل لـ `nodeIntegration` و`require`.
- **n10 بوابة IPC والتحقق من المسارات (IPC Gateway & Path Guard):** فحص مسارات الملفات لمنع Path Traversal (`..`) والروابط الرمزية غير المصرح بها، وتمرير الطلبات المشفرة بتوكن محلي.
- **n11 إدارة خدمة Python (Service Lifecycle Manager):** بدء وإيقاف ومراقبة خدمة FastAPI على المنفذ المحلي العشوائي مع مراقبة الصحة `/health`.

### 3. خدمة المحرك المحلية [n13] (Local Python Service - FastAPI)
- **n14 مسيّر الـ API المحلي (Local API Router):** حماية بـ Session Token محلي، رفض أي اتصال خارجي.
- **n16 مدير المهام (Task Manager):** طوابير المهام، نسب الإنجاز، الإلغاء الفوري التعاوني، ونقاط الاستئناف (Checkpoints).
- **n18 مدير المزودات (Provider Manager):** التوجيه الذكي (محلي دائمًا، خارجي لمهام محددة، تلقائي).
- **n19 توليد المخطط والمحتوى (Outline & Content Generator):** توليد مرحلي (مخطط أولاً ثم مراجعة ثم شرائح) مع التحقق من صحة JSON Schema.
- **n21 البحث والأدلة (Sources & Claims Log):** توثيق الادعاءات والمصادر ومنع اختراع الإحصائيات أو الاقتباسات الوهمية.
- **n22 الصور والرسوم البيانية (Media & Native Charts):** تتبع تراخيص الصور، وتوليد رسوم بيانية تفاعلية أصلية عبر OOXML.
- **n23 نموذج العرض الموحد (Unified Presentation Model):** المصدر الوحيد للحقيقة (Single Source of Truth) المشترك بين المعاينة والتصدير.
- **n24 محرك التصميم (Design Engine):** تطبيق التخطيطات والثيمات مع ضمان عدم حذف أي محتوى أو عنصر.
- **n26 فحص الجودة البصرية (Visual Quality Inspector):** كشف تداخل وفيض النصوص ومقاييس التباين WCAG 4.5:1.
- **n27 مصدّر PPTX (python-pptx + OOXML):** كتابة ملفات PowerPoint أصلية قابلة للتحرير بالكامل مع دعم العربية RTL.
- **n28 مدقق الحركات (Verified Animations Checker):** حقن حركات وانتقالات OOXML المختبرة والمتحقق من توافقها فقط.
- **n29 مستورد وفهرسة المكتبة (Library Importer & Classifier):** فحص نوع الملفات بالبصمة السحرية (Magic Bytes) وكشف التكرار بـ SHA-256.
- **n30 التعلّم من التفضيلات (Local Preference Learning):** ترجيح وتفضيل الثيمات بناءً على خيارات المستخدم محلياً مع خيار التعطيل والمسح.
- **n31 النسخ الاحتياطي (Backup & Restore):** أرشفة متسقة لقواعد البيانات والمشاريع.
- **n32 السجلات الآمنة (Safe Logger):** تسجيل تشخيصي مع حجب تلقائي (Redaction) للمفاتيح والبيانات الحساسة.

### 4. مزودات الذكاء الاصطناعي [n33]
- **n34 المحول المحلي الافتراضي (Ollama / Local API):** المسار الأساسي الخالي من الاتصالات الخارجية ومن أي API Key.
- **n36 بوابة الموافقة وسياسة المهام (Consent Gate):** أخذ موافقة المستخدم الشفافة قبل إرسال أي محتوى خارجياً.
- **n37 المحولات الخارجية (External Providers):** محولات مخصصة للمزودات المصرح بها عبر مفاتيح API.

### 5. التخزين المحلي ونظام التشغيل [n39]
- **n40 قاعدة بيانات SQLite:** البيانات الوصفية، فهارس المكتبة، التفضيلات والمهام.
- **n41 ملفات المشاريع JSON:** حفظ المشروع بصيغة JSON متوافقة مع `schema_version`.
- **n42 مجلد المكتبة الأصلي:** قراءة فقط لملفات المستخدم وقوالبه.
- **n44 مخزن الأسرار (Windows Credential Manager / safeStorage):** تخزين مشفر لمفاتيح API بعيداً عن السجلات والكود.
- **n46 ملف PPTX النهائي:** عرض تقديمي قابل للتحرير بالكامل.
